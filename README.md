# 우리 아이 미네랄 섭취 가이드

0세부터 만 15세까지 칼슘·마그네슘·철분·아연의 하루 권장 섭취량, 영양제 보충량, 상한 섭취량을 한국과 미국 기준으로 비교하는 웹페이지입니다.

## 기능

- 연령별 기준표: 한국(2020 한국인 영양소 섭취기준)과 미국(NASEM DRI) 비교
- 영양제 용량 계산기: 음식별 섭취 횟수로 식사량을 추정하고 보충량과 최대 허용량 계산
- 복용 기간 가이드: 상한섭취량 정의와 소아 치료 지침(AAP, WHO) 기반
- 미네랄별 주의사항

## 사용 방법

`index.html`을 브라우저에서 열면 됩니다. 별도 설치가 필요 없습니다.

## 주의

이 페이지는 일반 정보이며 의학적 진단이나 처방을 대신하지 않습니다. 음식별 미네랄 함량은 근사값이며, 한국 기준은 2020년판을 바탕으로 했습니다(2025년 개정판 확인 권장).
